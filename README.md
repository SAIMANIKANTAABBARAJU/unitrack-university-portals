# UniTrack University Portal

React + Vite + TypeScript application.

## Run locally

1. Install Node.js (LTS).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Deploy
Import this repository into Vercel. Build command: `npm run build`. Output directory: `dist`.

This current version stores demo data in the browser's local storage. It is not yet connected to a shared database/authentication backend; do not use real student records until backend security is implemented.
